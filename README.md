## Quick Start

### 1. Open in Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/yourusername/dnd-2024-generator/blob/main/DND_2024_Character_Generator.ipynb)

### 2. Set Up Gemini API Key

**Get Your Free API Key:**
1. Visit https://aistudio.google.com/app/apikey
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the generated key

**Add to Colab Secrets:**
1. Click the 🔑 key icon in the left sidebar
2. Click "+ Add new secret"
3. Name: `GEMINI_API_KEY`
4. Value: Paste your API key
5. Toggle "Notebook access" ON

> **Important:** Never paste API keys directly in code cells. Always use Colab Secrets for security.

### 3. Run the Notebook

1. Run the first cell to install dependencies (~30 seconds)
2. Configure your character options in the "Character Options" cell
3. Run cells in order to generate your character
4. Download the PDF character sheet

### Ability Score Methods

The notebook uses **Standard Array** by default: [15, 14, 13, 12, 10, 8]

Scores are intelligently assigned based on class priorities:
- **Barbarian:** STR → CON → DEX
- **Bard:** CHA → DEX → CON
- **Cleric:** WIS → CON → STR
- **Fighter:** STR → CON → DEX
- **Ranger:** DEX → WIS → CON
- **Rogue:** DEX → INT → CON
- **Wizard:** INT → CON → DEX

Background bonuses are applied automatically (+2 to primary, +1 to secondary).

## How It Works

### 1. Character Generation Engine

The notebook implements complete D&D 2024 rules:

**Ability Scores:**
- Standard Array assignment based on class
- Background ability bonuses (+2/+1)
- Enforces level 1 maximum of 18

**Derived Statistics:**
- Ability modifiers: `(score - 10) // 2`
- Hit Points: Max hit die + CON modifier
- Armor Class: 10 + DEX mod + armor
- Initiative: DEX modifier
- Proficiency Bonus: +2

**Proficiencies:**
- Skills from class (2-4 choices) + background (2 skills)
- Saving throws (2 from class)
- Armor, weapons, tools
- Languages from species + background

**Features:**
- Species traits (darkvision, resistances, special abilities)
- Class features (fighting styles, spellcasting, etc.)
- Origin Feat from background
- Weapon Mastery (martial classes)

**Equipment:**
- Class starting equipment
- Background tool proficiency
- 50 GP starting gold (2024 standard)

**Spellcasting:**
- Spell save DC: 8 + proficiency + ability modifier
- Spell attack bonus: proficiency + ability modifier
- Prepared spells: ability modifier + level
- Cantrips and 1st-level spells assigned

### 2. AI Narrative Generation

Uses Google Gemini API to generate:

**Physical Description (3-4 sentences):**
- Appearance reflecting species traits
- Build based on ability scores (high STR = muscular)
- Distinguishing features
- Clothing/equipment style

**Personality Elements:**
- 2 personality traits (reflecting high/low stats)
- 1 ideal (philosophical belief)
- 1 bond (personal connection)
- 1 flaw (interesting weakness)

**Backstory (3 paragraphs):**
- Paragraph 1: Childhood and background origins
- Paragraph 2: How they learned class abilities
- Paragraph 3: Current motivations for adventuring

The AI considers all character stats to create coherent, fitting narratives.

### 3. PDF Generation

Creates a professional 2-3 page character sheet using WeasyPrint:

**Page 1: Core Stats**
- Header with name, species, class, background
- Ability score grid with modifiers
- Core stats (AC, HP, initiative, speed)
- All 18 skills with proficiencies marked
- Saving throws
- Combat section with attack bonuses
- Proficiencies and languages

**Page 2: Features & Equipment**
- Species traits with descriptions
- Class features
- Origin Feat
- Equipment list
- Starting gold
- Spellcasting section (if applicable)

**Page 3: Personality & Backstory**
- Physical description
- Personality traits, ideal, bond, flaw
- Complete backstory narrative

## Troubleshooting

### "GEMINI_API_KEY not found"

**Solution:**
1. Get API key from https://aistudio.google.com/app/apikey
2. Add to Colab Secrets (🔑 icon in sidebar)
3. Name must be exactly `GEMINI_API_KEY`
4. Toggle "Notebook access" ON

### "Model not found" Error

The notebook tries multiple Gemini models automatically. If all fail:
1. Verify your API key is valid
2. Check you have access to Gemini API
3. Wait a few minutes and try again (rate limiting)

### PDF Generation Fails

**Solution:**
1. Run the dependency installation cell again
2. Restart runtime (Runtime → Restart runtime)
3. Ensure WeasyPrint dependencies installed correctly

### AI Generates Invalid JSON

The notebook has fallback templates if AI generation fails. Character will still be created with placeholder narratives.
